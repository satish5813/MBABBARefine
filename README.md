# MBA — KL University Pathways

React + Tailwind app showcasing the MBA Business Builder (BB) pathway:
global low-cost / free certifications mapped to MBA roles, 30+ LPA role
paths, domain roadmaps and student pathways.

## Run

```bash
cd mba-app
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tabs

- **BB** — Business Builder overview, highlights and source notes
- **Program Objectives** — objectives and expected outcomes
- **Domain Pathways** — free-first → low-cost roadmaps per domain
- **30+ LPA Role Paths** — premium role plans with stacks and 90-day actions
- **Certifications** — searchable catalog of formal certifications with
  ratings, costs and links to the student pathway
